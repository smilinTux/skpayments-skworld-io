Features

Everything the billing layer needs. Nothing it doesn't.

Built for self-hosted SKStack deployments. No vendor lock-in, no SaaS pricing.

🏗

Multi-app architecture

Register any number of apps in a JSON config file. One SKPayments instance serves all of them.

⚡

LiteLLM auto-provisioning

On payment success, the user's LiteLLM budget and rate limits are updated automatically via API.

🔐

Stripe webhook verification

All Stripe events are HMAC-SHA256 verified. Signature mismatches return 400 and are logged.

🔄

Full subscription lifecycle

Checkout, plan changes, cancellations, and payment failures all handled. Downgrades to free tier automatically.

🗄

Zero external dependencies

SQLite for customer records. Stripe via raw HTTPS (no SDK). Runs on the open-webui base image.

🐳

Docker Swarm native

One service, one stack file, bind-mounted config. Traefik labels included. Deploys in under a minute.

API

Simple REST interface

All endpoints return JSON. No auth required for checkout — the app backend calls on behalf of the user.

POST/checkout/{app_id} — Start a checkout session

// Request
{ "user_id": "uuid", "email": "user@example.com", "tier": "pro" }

// Response
{ "checkout_url": "https://checkout.stripe.com/c/pay/cs_..." }

POST/portal/{app_id} — Manage subscription

// Request
{ "user_id": "uuid" }

// Response
{ "portal_url": "https://billing.stripe.com/p/session/..." }

GET/status/{app_id}/{user_id} — Current tier

// Response
{
  "app_id": "skai",
  "user_id": "uuid",
  "tier": "pro",
  "stripe_subscription_id": "sub_xxx"
}

POST/webhook/stripe — Stripe webhook target

// Register in Stripe Dashboard → Webhooks:
// https://pay.nativeassetmanagement.com/webhook/stripe
// Events: checkout.session.completed, customer.subscription.*
